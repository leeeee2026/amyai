# 智能按摩椅语音助手 · 用户使用手册

版本：v1.0
适用硬件：DNESP32S3B 语音控制模块（配按摩椅主控板）

---

## 一、它能做什么

对着按摩椅说话，就能控制按摩椅、听音乐、聊天。

| 能力 | 说明 | 响应速度 |
|---|---|---|
| **按摩控制** | 启停、力度、部位、手法、热敷、气囊、角度、时间、程序 | **约 0.5 秒**（本地识别）|
| **音乐播放** | 放歌、切歌、停止，支持雨声/海浪/森林等环境音 | 约 1~2 秒 |
| **闲聊问答** | 讲笑话、回答问题、聊天 | 约 2~3 秒（云端）|
| **休眠** | 说「退下」后停止聆听，需要再说唤醒词才恢复 | 立即 |

## 二、快速上手（3 步）

### 第 1 步：上电

接通电源，指示灯亮起。听到提示音后约 3 秒，设备自动连接 WiFi。

### 第 2 步：首次配网（仅第一次需要）

1. 手机打开蓝牙
2. 搜索名为 **AMYAI-XXXX** 的设备并连接（配对码 `abcd1234`）
3. 在配网页面输入 WiFi 名称和密码
4. 配网成功后设备自动重启，听到「网络就绪」即可使用

> 之后每次上电会自动重连，不需要再配网。
> 如果要重新配网：按住配网键 3 秒，设备会重启并进入配网模式。

### 第 3 步：唤醒它

```
你：「小鹿小鹿」
设备：「在的」          ← 约 1 秒后回应
```

听到「在的」之后，**直接说要做什么**就行。

## 三、语音交互基础

### 3.1 唤醒词

设备平时处于待机状态，只有听到 **「小鹿小鹿」** 才会响应。

### 3.2 说完自动结束

说完话后**停顿约 0.5 秒**，设备会自动判断"说完了"，开始处理。
不需要按任何键，也不会一直录下去（最长 6 秒）。

### 3.3 连续对话（10 分钟内免唤醒）

设备回复完之后，**10 分钟内可以接着说下一句，不用再喊唤醒词**。

```
你：「小鹿小鹿」
设备：「在的」
你：「按按肩」
设备：「好的，马上为您调整」      ← 本地识别，约 0.5 秒
你：「重一点」                    ← 直接说，不用再唤醒
设备：「好的，马上为您调整」
你：「放首歌」                    ← 也可以直接说
```

### 3.4 两种应答提示

| 听到什么 | 含义 |
|---|---|
| **「好的，马上为您调整」** | 本地识别成功，指令已下发（很快）|
| **「好的」** | 这句本地没听懂，正在交给云端处理（稍慢，会有完整回复）|

### 3.5 休眠（退下）

不想用了可以说 **「退下」**：

```
你：「退下」
设备：「好的，有需要随时叫我」
之后：随便说话都没反应，直到再喊「小鹿小鹿」
```

可以用这些说法：**退下 / 退下吧 / 没事了 / 不用了**

## 五、音乐功能

### 5.1 放音乐

```
你：「小鹿小鹿」
设备：「在的」
你：「放首歌」
设备：直接开始播放（不播报，约 1~2 秒出声音）
```

### 5.2 支持的曲目和说法

| 你可以这么说 | 播放内容 |
|---|---|
| 放首歌 / 来首歌 / 背景音乐 | 轻音乐 |
| 来点雨声 / 下雨声 / 白噪音 | 雨声 |
| 海浪 / 来点海浪声 | 海浪 |
| 森林 / 来点鸟叫声 | 森林鸟鸣 |
| 助眠 / 睡觉听的 | 助眠音乐 |
| 春天 / 轻快的 | 春日轻快 |
| 动感 / 节奏感强的 | 动感节奏 |

也可以直接说：**「放点钢琴曲」「来点小星星」**

### 5.3 放音乐时怎么切歌 / 停止（不用唤醒词！）

音乐播放期间，**直接说就行**，不需要先喊「小鹿小鹿」：

| 你可以这么说 | 效果 |
|---|---|
| 换一首 / 下一首 / 下一个 / 再来一首 | 切到下一首 |
| 停 / 停止 / 关掉 / 别放了 / 关了吧 | 停止播放（不说话，直接静音）|

> ⚠️ 音乐播放中，**其他话（比如「讲个笑话」）会被忽略**。
> 想聊天请先喊「小鹿小鹿」，音乐会自动暂停，聊完继续放。

### 5.4 音乐音量说明

音乐播放时会自动把音量降到 **40%**，这是为了让麦克风听清你的指令。
停止音乐后自动恢复 100%。

> 如果觉得音乐太小/太大，管理员可以在编译配置里调整（`AMYAI_MUSIC_DUCK_PERCENT`，默认 40%）。

## 六、闲聊问答

唤醒后直接问，设备会用语音回答（边想边说，不用等整段生成完）。

### 6.1 示例

```
你：「讲个笑话」
设备：（讲一个笑话）

你：「再讲一个」              ← 记得上文，会换一个
设备：（另一个笑话）

你：「今天天气怎么样」
设备：「我现在还查不到实时天气。」

你：「你叫什么名字」
设备：「我是你的按摩椅助手。」

你：「你能干什么」
设备：「我能帮你按按摩、调力度、开热敷。」
```

### 6.2 支持的多轮对话

设备会记住**最近 3 轮**对话，所以可以这样接：

```
你：「讲个笑话」
你：「再讲一个」          ← 知道要换一个
你：「太长了，短一点」    ← 知道在说笑话
```

### 6.3 闲聊响应较慢是正常的

| 环节 | 耗时 |
|---|---|
| 语音识别 | ~0.7 秒 |
| 大模型生成 | ~1~1.5 秒（首字）|
| 语音合成首包 | ~0.6 秒 |
| **合计** | **约 2~3 秒开始说话** |

而且设备是**边说边生成**的，长回复会一边说一边继续生成，不会卡住。

## 七、使用技巧

### ✅ 建议这样做

| 技巧 | 说明 |
|---|---|
| **等「在的」说完再说话** | 应答有 0.5 秒延迟，说完再说不会漏字 |
| **一次说一件事** | 「按按肩」比「按按肩然后重一点再来点热敷」更准 |
| **距离 0.5~2 米** | 太远识别率下降 |
| **正常语速，不用喊** | 说话不清楚时可以稍慢一点 |
| **长命令稍等一下** | 说 6 个字以上时设备会自动多录一点 |

### ⚠️ 注意事项

| 情况 | 说明 |
|---|---|
| 环境太吵（电视、大声说话）| 识别率会下降，建议靠近一点说 |
| 音乐播放中 | 只有「换一首/停」有效，其他话会被忽略 |
| 说完话没反应 | 可能没唤醒成功，再喊一次「小鹿小鹿」|
| 说了「退下」之后 | 任何话都没反应，需要重新喊「小鹿小鹿」|
| 网络断了 | 按摩控制**仍可用**（本地识别），闲聊和音乐不可用 |

## 八、常见问题（FAQ）

**Q1：喊「小鹿小鹿」没反应？**
A：① 确认电源和指示灯；② 是否说过「退下」（休眠了）；③ 距离是否太远；④ 环境是否太吵；⑤ 重启一次。

**Q2：说了指令没反应，但听到「好的」？**
A：这句本地没听懂，正在走云端。等 2~3 秒，如果还是没反应，说明网络或云端服务有问题。

**Q3：听到「好的，马上为您调整」但按摩椅没动？**
A：说明语音识别成功了，但和主控板的通信出了问题（接线松动或主控板未上电）。

**Q4：放歌没声音？**
A：① 曲库服务器是否在线（需要一台机器提供音乐文件）；② 说「停止」再重新说「放首歌」试试。

**Q5：放音乐时说话没反应？**
A：正常。音乐播放中只响应「换一首」和「停」，想聊天请先喊「小鹿小鹿」。

**Q6：设备偶尔重启？**
A：可能是网络异常或内存不足。记录重启前的操作，联系技术支持。

**Q7：能改唤醒词吗？**
A：唤醒词在出厂固件中固定为「小鹿小鹿」，不支持下改。

**Q8：能离线用吗？**
A：按摩控制（144 条指令）**完全离线**可用；闲聊、放歌需要联网。
