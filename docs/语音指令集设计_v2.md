# 语音指令集设计 v2（按摩椅）

> 目标：让大模型把用户的口语稳定、安全地解析成一份设备能执行的结构化指令。
> 现状：v1 只有 `start/stop/pause/set_zone/set_level/set_time/query_status/unknown`，
> 覆盖不了"节奏""腿托升降""只调某个部位"这类真实需求。

---

## 1. 主流按摩椅的功能维度（行业调研）

市面上的中高端按摩椅（荣泰、奥佳华、傲胜、松下、OSIM、稻田等），遥控器/App 上能调的维度基本就是这几类：

| 维度 | 常见取值 | 遥控器表现 | 用户口语 |
|---|---|---|---|
| **部位** | 颈肩、肩部、背部、腰部、臀部、腿部、足部、手臂、全身 | 分段选择/机身示意 | "按按肩膀""脖子酸""腰有点累""全身放松" |
| **手法** | 揉捏、敲击、指压、揉敲、推拿、振动、拉伸 | 手法键循环 | "揉一揉""捶一捶""用指压""推拿模式" |
| **力度** | 1–5 档（轻/中/重） | 力度 +/− | "重一点""太疼了""轻点" |
| **速度/节奏** | 1–5 档 或 慢/中/快 | 速度键 | "慢一点""快一点""节奏太快了" |
| **气压（气囊）** | 0–5 档 | 气压 +/− | "气太紧了""松一点" |
| **靠背角度** | 约 100°–170°（坐→躺） | 靠背升/降 | "躺下来一点""坐起来" |
| **腿托角度** | 0°–90°（放下→抬起） | 腿托升/降 | "腿抬高一点""腿放低" |
| **零重力** | 开/关（两段式） | 零重力键 | "零重力""躺平模式" |
| **热敷** | 开/关（腰/背/腿） | 加热键 | "开个热敷""太热了关掉" |
| **定时** | 10/15/20/30 分钟 | 时间键 | "二十分钟""半小时" |
| **自动程序** | 舒眠、解乏、颈肩重点、全身放松、久坐恢复、运动恢复 | 程序键 | "来个解乏的""睡眠模式" |

**关键观察**：

1. 用户很少说"第几档"，绝大多数是**相对表达**（"再重点""轻一点"）
2. 用户经常**只给维度不给数值**（"腿有点高" → 降低腿托，降多少不知道）
3. 用户会**组合说**（"重点按肩膀，轻一点"）
4. **"疼/不舒服"是最高优先级的降强度信号**

## 2. 设计原则

1. **绝对和相对分开**
   `set_*` 给具体值，`adjust_*` 给增量。LLM 只负责判断"是哪种"，具体加减和设备状态由固件结合当前值算。
2. **必须能表达作用域（scope）**
   "重一点" = 全局；"肩膀重一点" = 只作用于肩部。用一个可选 `zones` 字段承载。
3. **相对指令依赖上下文**
   提示词里必须注入**当前设备状态**（力度/速度/角度/程序/部位），否则"再重一点"无从算起。
4. **LLM 不做边界裁剪**
   它可能输出 `level: 9`，固件裁剪到 1–5。LLM 只保证字段名和类型正确。
5. **一句多意图**
   支持 `actions` 数组；只有单个意图时也允许直接输出对象（兼容简单机型）。
6. **安全词永不过网关**
   停/急停/别按 这类词在本地识别，直接发急停帧，**不走 LLM**（延迟和安全都不允许）。

## 3. 指令集 v2

### 3.1 输出格式

单意图：

```json
{"cmd":"set_intensity","level":3}
```

多意图（一句里说了两件事）：

```json
{"actions":[
  {"cmd":"set_zone","zones":["shoulder"]},
  {"cmd":"adjust_intensity","delta":1}
]}
```

### 3.2 指令清单

| cmd | 参数 | 取值范围 | 说明 |
|---|---|---|---|
| `start` | — | — | 开始按摩（沿用上次程序） |
| `stop` | — | — | 停止（回中、泄气） |
| `pause` | — | — | 暂停 |
| `resume` | — | — | 继续 |
| `set_zone` | `zones[]` | neck/shoulder/back/waist/hip/leg/foot/arm/full | 指定按摩部位，可多选 |
| `set_intensity` | `level` | 1–5 | 力度绝对值 |
| `adjust_intensity` | `delta`，可选 `zones[]` | -2…+2 | 力度相对调整 |
| `set_speed` | `level` | 1–5 | 节奏速度绝对值 |
| `adjust_speed` | `delta` | -2…+2 | 速度相对调整 |
| `set_mode` | `mode` | knead/tap/press/knead_tap/shiatsu/vibrate/stretch | 手法 |
| `set_airbag` | `level` | 0–5（0=关） | 气囊气压 |
| `set_heat` | `on`，可选 `zones[]` | true/false | 热敷 |
| `set_recline` | `angle` | 100–170（度） | 靠背角度绝对值 |
| `adjust_recline` | `delta` | -30…+30 | 靠背相对调整 |
| `set_leg_rest` | `angle` | 0–90（度） | 腿托角度绝对值 |
| `adjust_leg_rest` | `delta` | -30…+30 | 腿托相对调整 |
| `set_zero_gravity` | `on` | true/false | 零重力 |
| `set_time` | `minutes` | 5–60 | 定时 |
| `set_program` | `program` | sleep/relax/neck_shoulder/full_body/office_recovery/sport_recovery | 自动程序 |
| `query_status` | — | — | 查询当前状态 |
| `unknown` | — | — | 听不懂或与按摩无关 |

> **命名约定**：`set_` 是绝对值，`adjust_` 是相对值。这两个前缀是给 LLM 的强提示，
> 让它自己去区分"调到三档"和"再重一点"。

## 4. 口语 → 指令映射（样例库）

| 用户说的 | 输出 |
|---|---|

| 重一点 | `{"cmd":"adjust_intensity","delta":1}` |

| 调到三档 | `{"cmd":"set_intensity","level":3}` |
| 节奏慢一点 | `{"cmd":"adjust_speed","delta":-1}` |
| 快一点 | `{"cmd":"adjust_speed","delta":1}` |
| 腿抬高一点 | `{"cmd":"adjust_leg_rest","delta":10}` |
| 腿放低 | `{"cmd":"adjust_leg_rest","delta":-20}` |
| 腿抬到最高 | `{"cmd":"set_leg_rest","angle":90}` |
| 躺下来一点 | `{"cmd":"adjust_recline","delta":20}` |
| 坐起来 | `{"cmd":"set_recline","angle":110}` |
| 来个零重力 | `{"cmd":"set_zero_gravity","on":true}` |
| 全身重一点 | `{"cmd":"adjust_intensity","delta":1,"zones":["full"]}` |
| 用揉捏的 | `{"cmd":"set_mode","mode":"knead"}` |
| 捶一捶背 | `{"actions":[{"cmd":"set_mode","mode":"tap"},{"cmd":"set_zone","zones":["back"]}]}` |
| 开热敷 | `{"cmd":"set_heat","on":true}` |
| 气太紧了 | `{"cmd":"adjust_intensity","delta":-1}` 或 `{"cmd":"set_airbag","level":2}` |
| 来个半小时的 | `{"cmd":"set_time","minutes":30}` |
| 来个解乏的 | `{"cmd":"set_program","program":"relax"}` |
| 现在什么状态 | `{"cmd":"query_status"}` |
| 帮我订张机票 | `{"cmd":"unknown"}` |

## 5. 提示词改造要点

1. **注入当前状态**（每次请求都带上，否则相对指令没法算）：

```
当前状态：模式=揉捏，力度=3/5，速度=2/5，靠背=120°，腿托=20°，部位=全身，剩余=18分钟
```

2. **明确相对 vs 绝对**：
   "一点/稍微/再/太…了" → `adjust_*`；"调到 N 档/最高/最低/最轻" → `set_*`

3. **缺省作用域**：
   没提部位 → 不输出 `zones`（固件理解为"当前部位/全局"）

4. **多意图拆分**：
   一句话里出现"部位 + 其他维度"时用 `actions` 数组

5. **否定优先**：
   "别按了/停下/太疼了" 里，停止和降强度优先于其他意图

6. **输出约束**：
   单行 JSON、不要 Markdown、不要解释、字段名必须用英文字面量

## 6. 安全边界（固件侧，不依赖 LLM）

| 项 | 规则 |
|---|---|
| 急停词 | 停/停一下/别按/急停 → 本地直发 0x04，<100ms，不走云端 |
| 力度裁剪 | 1–5，超范围裁剪 |
| 角度限位 | 靠背 100–170°，腿托 0–90° |
| 时长上限 | 60 分钟 |
| 未知指令 | 解析失败或 `unknown` → **不下发** |
| 心跳超时 | **已取消**（产品要求只在有数据时通信）；链路断开靠 ACK 超时判断 |
| 越界保护 | 收到超出机械行程的角度 → 拒绝并回 NACK |
