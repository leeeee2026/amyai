# 离线命令词表（MultiNet7 中文）

> **这是离线命令词的唯一数据源。**
> 改完这张表，执行 `python tools/gen_local_asr.py` 即可：
> 1. 自动补全「拼音」列（留空就行，脚本会用 pypinyin 生成）
> 2. 生成 `main/local_asr_cmds.h`（固件用的词表）
> 3. 把补好的拼音写回本文件

## 编辑规则

| 规则 | 说明 |
|---|---|
| **指令ID** | 1~200，同一 ID 的多行 = 同义词，都会触发同一个指令 |
| **中文说法** | 用户实际会说的话（1~6 个字最稳） |
| **拼音** | 留空即可，脚本自动生成；多音字不对时可手动填（不带声调、空格分隔） |
| **下发指令** | 与云端完全一致的 JSON，字段见 `docs/语音指令集设计_v2.md` |
| **总量上限** | MultiNet 最多 200 条短语 |

## 注意事项

- 不改「指令ID」的语义（比如 1 一直是"开始按摩"），否则历史行为会变
- 同义词之间拼音**不能完全相同**（会互相覆盖）
- 短语里不能有阿拉伯数字和特殊符号
- 增加短语会增加模型内存和一点 CPU，140 条左右很轻，200 条是上限
